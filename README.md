Excited to share our first simulation project in Silicon Photonics! 🚀

As part of my journey into Photonic Integrated Circuits (PIC) design, We recently modeled and validated a standard Silicon-on-Insulator (SOI) strip waveguide (450 x 220 nm) operating at lambda approx 1550 nm using open-source photonics tools (MPB, Meep, and Python).

Key Highlights & Results:
1. Mode Solver & Profiles: Extracted fundamental TE0 (n_eff approx 2.354) and TM0 modes with precise field distribution analyses.
2. Group Index (n_g): Calculated n_g approx 4.29, aligning closely with literature benchmarks for microring resonators.
3. Bend Loss Analysis: Evaluated radiation losses across various bending radii using FDTD (R = 1.5 um to 2.5 um and beyond).
4. Fabrication Tolerance: Quantified width sensitivity (dn_eff / dw approx 2.16 × 10⁻³ nm⁻¹) for +/- 10 nm variations.

A huge thanks to foundational literature benchmarks (W. Bogaerts et al., Chrostowski & Hochberg) for guiding this sanity check. Looking forward to sharing more milestones on PIC design and optical simulation!
